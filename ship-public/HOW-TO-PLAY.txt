COOP SEKIRO 1.3.6-beta - quick guide
===============================
By xCløuD (forked from Sekiro Together by Tihvert)

Back up your saves before playing.

YOU NEED
- Sekiro on Steam, version 1.06 (normal, unmodded)
- Windows (or Linux / Steam Deck with Proton; see LINUX / STEAM DECK below)
- No mod loader (me3) needed!

INSTALL (DRAG AND DROP)
1. Got Sekiro Online or other online mods? Delete dinput8.dll, steam_api64.org,
   cream_api.ini and SekiroOnlineFont.ttf from the game folder, then
   Steam > Sekiro > Properties > Installed Files > Verify integrity.
2. Extract/drag `coop_sekiro_launcher.exe` and the `CoopSekiro` folder
   directly into your Sekiro game folder (the folder containing sekiro.exe).
   - Launching Sekiro from Steam starts the normal unmodded game.
   - Running `coop_sekiro_launcher.exe` launches CooP Sekiro.
   Neither interferes with the other.
3. By default (`steam_invites = 1` in `CoopSekiro\sekiro_coop_settings.ini`),
   no password is needed for Steam invites! For Steam password lobbies or Direct
   UDP (`Connection mode = Direct UDP` in-game or `transport = udp`), set the same
   `password = ...` on everyone.
4. Everyone needs the exact same mod version.

PLAYING (STEAM INVITES - DEFAULT)
1. Make sure Steam is open, run `coop_sekiro_launcher.exe`, and load your save.
2. After the intro (Genichiro beats you, you wake up at Dilapidated Temple)
   rest at the temple idol. You get:
   - Kindred Bell   = open your world (host) / re-ring to open Steam Invite UI
   - Kindred Charm  = join host world (Steam password or Direct UDP mode)
   - Severed Thread = leave co-op
3. Host rings the Kindred Bell to open a strictly private invite-only lobby,
   then uses the Kindred Bell a second time while waiting to open the Steam
   invite menu and invite friends.
4. Invited friends accept the Steam invite in their Steam Overlay ("Join Game")
   and connect automatically — nobody outside your invited friends can find or
   join your lobby. Status is in the top left corner.
5. Settings: `CoopSekiro\sekiro_coop_settings.ini` or Options > CooP Sekiro Settings in game.

DROPPING & PICKING UP ITEMS
- As soon as your world is open (Kindred Bell active — even before a companion joins)
  or while connected in co-op, open your Inventory, hover any consumable or prosthetic
  upgrade material, and press Y / Triangle (controller) or Y (keyboard) to open the
  Drop Item quantity dialog (1 to total held). Prompts adapt automatically between
  controller and keyboard/mouse, and background Inventory navigation pauses while
  the dialog is open.
- Choose how many to drop (D-pad / sticks / Arrow keys / WASD / buttons or slider)
  and confirm with A / Y / Enter / Confirm Drop, or press B / Esc / Cancel to back out.
- Optional quick list: press F6 on keyboard to open the side "Drop Item (Co-op)" panel.
- Dropped items appear at your feet as a tied cloth pouch with a pale light beam,
  butterflies, and item name above it. Walk near a dropped item and press E
  (keyboard) or X / Square (controller) to pick it up (hosts can also pick back up
  their own drops at any time). Key items, gourds, and unique quest items cannot be dropped.
- Merchant shops (like Memorial Mobs) keep individual stock per player: one player
  buying an item will not consume another player's shop stock.

STOPPING
1. Everyone uses the Severed Thread, joiners first and host last.
   Joiners get a loading screen and are back in their own world.
2. Then Quit Game from the menu, or Alt+F4.
Quit Game is greyed out while you're still in co-op, that's on purpose.
Don't close the game from Task Manager unless it's frozen (so log.txt can
record whether the game exited cleanly).

CONNECTION MODES (CoopSekiro\sekiro_coop_settings.ini or Options > CooP Sekiro Settings)
- `steam_invites = 1` with `transport = auto` (default): Private invite-only Steam
  lobbies. Only invited Steam friends can join; never public or searchable. No password
  needed unless falling back to UDP.
- `steam_invites = 0` with `transport = auto | steam`: Password-matched Steam lobbies.
  Requires the same `password = ...` on everyone. Host uses Kindred Bell and Joiners
  use Kindred Charm. Falls back to Direct UDP if Steam is unavailable when `auto`.
- `transport = udp` (or Connection mode = Direct UDP in Options > CooP Sekiro Settings):
  Connects directly over UDP immediately with no Steam dependency (requires the same
  `password = ...` on everyone; no need to change `steam_invites`).

DIRECT UDP (set Connection mode = Direct UDP in-game, or transport = udp in CoopSekiro\sekiro_coop_settings.ini)
Host:
1. Set `password = ...` in CoopSekiro\sekiro_coop_settings.ini and switch Connection mode
   to Direct UDP (or set `transport = udp`). With `transport = auto`, Steam fallback also
   uses Direct UDP automatically if a password is set.
2. Load your save and use the Kindred Bell. The join code only shows up after
   ringing the Bell, not at game start.
3. The mod tries to open port 28100 UDP on your router (UPnP). If it works,
   the top left shows "join code 1.2.3.4:28100" and the same code is saved
   to CoopSekiro\udp_join_code.txt (deleted when the session closes).
4. If UPnP is unavailable, the top left displays your local LAN IP for LAN play,
   or you can forward UDP 28100 to your PC in your router and share `<public ip>:28100`.
5. Send the join code to everyone joining.
Joiners:
1. Set Connection mode to Direct UDP (or `transport = udp`) and `udp_host_address = <host's join code>`,
   e.g. `udp_host_address = 1.2.3.4:28100`
2. Set the same `password = ...` as the host.
3. Load your save and use the Kindred Charm.
Only the host needs an open port. All joiners use the same address.
Can't open ports? A virtual LAN (Radmin VPN, ZeroTier, Tailscale) or local LAN works:
everyone joins the same network and joiners use the host's LAN/VPN IP as
`udp_host_address`. No port forwarding needed then.

SAVES
CooP Sekiro uses its own completely isolated save `S0000.co2` (starts clean, never
copies or modifies your vanilla `S0000.sl2`).
Backups: %LOCALAPPDATA%\sekiro-coop\save-backups\

BUGS
Log: %LOCALAPPDATA%\sekiro-coop\log.txt
Press F11 (or Back/Share on a pad) when a bug happens, it marks the log.

LINUX / STEAM DECK
Untested directly on Linux, runs through Proton like other standalone .exe launchers:
1. Start Sekiro once from Steam normally, quit at the main menu.
2. Copy `coop_sekiro_launcher.exe` and `CoopSekiro\` into your Sekiro game folder.
3. Add `coop_sekiro_launcher.exe` to Steam as a Non-Steam Game, enable Proton
   in Compatibility, and set Launch Options so it shares Sekiro's prefix:
   STEAM_COMPAT_DATA_PATH="$HOME/.local/share/Steam/steamapps/compatdata/814380" %command%
   (Or run `protontricks-launch --appid 814380 coop_sekiro_launcher.exe`.)
Files inside Sekiro's Proton prefix:
  ~/.local/share/Steam/steamapps/compatdata/814380/pfx/drive_c/users/steamuser/
    AppData/Local/sekiro-coop/   log.txt, save-backups
    AppData/Roaming/Sekiro/      saves (S0000.sl2 and S0000.coop.sl2)
See docs/LINUX.md for Flatpak, Steam Deck, and firewall notes.
